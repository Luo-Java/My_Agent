## 修复首页白屏：v-else 后非法跟 v-else-if（15:2x-15:37，MVN_EXIT=0）
- 现象：RAG 功能上线后 http://localhost:8080/ 空白页。headless Chrome 实证：DOM 仅 594B（#app 空壳），console 报 `Uncaught SyntaxError ... #compiler-30`。
- 根因：`index.html` 三个主视图分支（main.chat 内）——L73 `<template v-if="mainView==='chat'">`（聊天）、L136 `<div v-else class="agent-manage">`（智能体管理，**裸 v-else 兜底**）、L167 新增 `<div v-else-if="mainView==='kbs'">`（知识库）。Vue 编译规则：`v-else-if` 必须紧跟 `v-if`/`v-else-if`，**不能跟在 v-else 之后** → 编译错误码 30（v-else/v-else-if no adjacent v-if）→ 整页挂载失败白屏。加知识库视图时插错了位置。
- 修复：L136 `v-else` → `v-else-if="mainView === 'agents'"`（三分支显式互斥，mainView 取值仅 chat/agents/kbs，无兜底遗漏）。
- 验证：headless Chrome 渲染后 DOM 594B→46KB，侧栏「新建对话/对话历史/知识库」全渲染，console 零错误。已重新打包 jar（MVN_EXIT=0）并重启服务（PID 25492，端口 8080）。
- **教训/检查清单**：在 Vue 模板里，`v-if/v-else-if/v-else` 链中 v-else 必须是最后一个分支，其后不能接 v-else-if；给既有 v-if/v-else 链加新分支时，把原 v-else 改为 v-else-if=原条件再追加。排查白屏先看浏览器 console 的 vuejs.org/error-reference 错误码链接，再定位模板。
- 排查技巧：Git Bash 下 `curl -o /dev/null` 会 write error（exit 23）造成 size=0 假象，需 `-o 真实文件` 验证；headless Chrome `--dump-dom` 是判断 Vue 是否挂载的最快手段。

## 分片重叠 overlap（20:0x-20:11，BUILD SUCCESS）
- 需求：分片时**保证相邻两片之间有重复数据**（重叠），避免语义落在块边界被切断，提升向量检索精准度。
- **ChunkingService 支持 overlap**：`chunk(text, strategy, overlap)`（默认 60，0=关闭，上限 200）；核心机制：
  - FIXED + 超长无分隔兜底 = **滑动窗口**（窗口 600、步长 600-overlap，相邻窗口天然共享 overlap 字符）；
  - PARAGRAPH/RECURSIVE/MARKDOWN = **语义整块/聚合预算统一为 limit=600-overlap**（超预算的段/句向下钻拆分，为重叠留空间）+ 产出后统一**缝合**（每块头部拼上一块尾部至多 overlap 字，单块仍 ≤600）；
  - 重叠唯一缩水场景：上一块不足 overlap（文本尾短块）→ 重叠=上一块全长。ov=0 完全等价旧行为。
- **kb_file 加列 chunk_overlap INT NOT NULL DEFAULT 60**（DDL 已执行 + schema.sql + KbFile.chunkOverlap）；listFiles 显式列含 chunk_overlap。
- **KbService**：registerFile(..., strategyKey, overlap)、rechunkFile(kbId,fileId,strategyKey,overlap)——overlap 缺省沿用文件当前值，**策略与重叠都未变才 no-op**；文件记录保存 chunkOverlap；日志含重叠。
- **Controller**：upload 加 ?overlap=（缺省 60）；rechunk body 加 overlap（解析 NumberFormatException 兜底）；/chunk-strategies 改为 {strategies, defaultOverlap:60, maxOverlap:200}。
- **前端**：上传区新增「块间重叠」下拉（0/40/60/100/150/200 字，动态文案）；文件行 meta 显示「重叠 X 字」；重分确认条策略旁加重叠下拉（openRechunk 默认取文件现值）；doRechunk 策略+重叠都同才提示无需操作；app.js 增 overlapOptions/overlapText/overlapLabel/overlapHint/uploadOverlap/defaultOverlap。
- 验证：临时 main 实测 4 策略 × ov∈{0,60,100} × 4 类文本——固定/兜底滑窗重叠精确等于配置；长段落（575 字段落拆块后）相邻每对重叠恒=配置值（60/60/60...）；短段落（<overlap）重叠=上一块全长；全部块 ≤600。`mvn package -o` BUILD SUCCESS（20:10:58），jar 含全部改动。**未启动服务**（用户约定）。
