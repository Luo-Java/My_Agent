## Mapper 显式 SQL 全部迁到 XML
- 审计 23 个 mapper：7 个 edu 本就有 XML；14 个无 XML 的均为纯 `BaseMapper` / `LambdaQueryWrapper`（无自定义方法，合法，不需要 XML）；仅 `AgentTraceMapper` / `LlmUsageMapper` 把 `@Select` 聚合 SQL 写成了注解，违反「显式 SQL 写 XML」约定。
- 改动：删两个 mapper 的 `@Select` 注解（保留嵌套 record `AnswerAgg` / `UsageAgg` 与方法签名），新建 `src/main/resources/mapper/ai/AgentTraceMapper.xml` 与 `LlmUsageMapper.xml`（namespace=接口全类名，`resultType` 用 `XxxMapper$AnswerAgg` 嵌套 record）。
- 验证：`bash .workbuddy/memory/run_mvn.sh` BUILD SUCCESS；jar 内含两份新 XML + 两个 `$AnswerAgg` / `$UsageAgg` class；全局 grep 确认 mapper 包内已无 `@Select` / `@Update` 等注解。
- 结论：无 XML 的 mapper 不等于缺文件，只有「有自定义 SQL 却没 XML / 注解」才需要补；本项目当前无此类缺失。
