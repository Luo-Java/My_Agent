## ChatService 拆分重构
原 `ChatService`（约 700 行，一身兼多职）按职责拆成 1 个编排门面 + 4 个专职 Service：

- `ChatService`（门面/协调者）：只保留公共入口 `chat()` / `stream()` / `generateAgentPrompt()`，及 `buildRequest` / `determineAgent` / `buildLongTermMemoryText` / `applyAgentOptions`。
- `ParamFillingService`：参数补全与追问（声明式 `paramSchema` + 追问计数上限 `MAX_CLARIFY=3`）。`ClarifyDecision` 作为 public static 嵌套类暴露给 ChatService。
- `AgentRouter`：未绑定智能体时的智能路由（输出 `ROUTE=<编码>` / `NONE`）。
- `MemoryMergeService`：对话结束后的滚动摘要合并（`SUMMARY_BATCH_SIZE=6`）。
- `PromptService`：`resolveSystemPrompt` + `generateAgentPrompt`。

## 关键约定（不要破坏）
- 全程**不使用 ObjectMapper 解析 LLM 返回结果**：路由用正则 `ROUTE=`，参数抽取用「key: 取值」逐行 + 正则，`paramSchema` 用正则提取。原因：模型 JSON 输出不稳定。
- 跨轮参数累积依赖 AI 自带记忆（`DbChatMemory`），**不新增 Conversation 字段**。
- `Conversation` 结构未改动；仅 `agent` 表加了 `param_schema` 列。
- 公共 API（`chat/stream/generateAgentPrompt`）位置不变，被 ChatController / AgentController 调用。

## 弹窗字段被遮住修复
现象：编辑/新增智能体弹窗字段多（系统提示词 + 参数区 + 模型/主题色）时底部字段与页脚被裁切、滚不到。
根因：`.modal` 是 flex 纵向容器，`.modal-body` 作为 flex 子项默认 `min-height:auto` 不收缩，内容顶破 `max-height` 后被 `.modal` 的 `overflow:hidden` 裁掉。
修复：`style.css` 给 `.modal-body` 加 `flex:1 1 auto; min-height:0;`（内部 overflow-y:auto 即可滚动）；弹窗宽度 480→560px；参数行从 6 列窄网格改为 2 列卡片式（参数键/显示名、必填/删除、提示语整行、可选项整行），并把删除按钮移到必填同行右侧。`index.html` 相应调整了 param-row 内 DOM 顺序。
